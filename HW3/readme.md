# Практика к уроку 4

Собрать мини-модель заказов и пройти её отладчиком.

1. Описать `struct Item` и `Order`.
2. Написать `NewOrder` с `error`.
3. Добавлять `Item` через `*Order`.
4. Посчитать сумму позиций.
5. Проверить код breakpoint и тестами.

Дополнительно (на основе примеров лекции):

- разобрать nil-receiver в непустом интерфейсе (`nil-receiver`), посмотреть в дебаге;
- попробовать перехват паники на разных уровнях (`04-recover-boundary`);
- написать свою кастомную ошибку с `Unwrap` и `Is` (`err-custom`).
